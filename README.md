# GovernIQ expert demo

Read-only research demonstration with real project dependency evidence and a separate synthetic ML benchmark.

## Deploy
Create a GitHub repository and upload the contents of this folder at its root.
In Streamlit Community Cloud choose the repository, main branch, and streamlit_app.py.
In Advanced settings select Python 3.12. No secrets are required.
https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy

## Local run
pip install -r requirements.txt
python -m streamlit run streamlit_app.py

## Scope
Includes real project names and source evidence, as authorised by the project owner.
Raw workbooks, dissertation drafts, training datasets, model binaries and participant responses are excluded.
The review register is a snapshot; no decisions or questionnaire responses are submitted by the app.
Keep a fixed snapshot per Delphi round and document changes between rounds.
The saved predictions are synthetic examples, not forecasts for the real portfolio.
